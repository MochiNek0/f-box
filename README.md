# F-Box

极简 Flash 游戏浏览器。现代浏览器停止支持 Flash 之后，F-Box 让那些游戏重新跑起来——自动识别插件、多标签、变速与自动化，开箱即用。

官网：**[fbox.dpdns.org](https://fbox.dpdns.org)** · [下载](https://fbox.dpdns.org/#download) · [常见问题](https://fbox.dpdns.org/faq/)

基于 Electron 构建，Windows / macOS，MIT 开源。

## 核心功能

### 基础浏览

- **原生 Flash 支持** — 自动扫描系统中的 Pepper Flash 插件，无需手动配置
- **多标签页浏览** — 同时运行多个游戏，快速切换
- **智能弹窗接管** — 自动接管弹窗游戏（如赛尔号、洛克王国）
- **托盘后台** — 最小化至系统托盘，随时待命

### 个性化体验

- **隐私老板键** — 全局快捷键（默认 `Esc`）一键隐藏/呼出窗口
- **窗口透明度** — 全局调节，与桌面背景融合
- **画面分辨率** — 「设置 → 显示」可选「自动」（匹配屏幕，高清渲染）或「原始」（固定 1280 宽）
- **可视化设置面板** — 集中调节各项参数

### 游戏辅助（Windows）

- **游戏库管理** — 内置精选游戏入口，支持自定义添加游戏链接
- **键位映射** — 基于 AutoHotkey，支持键盘重映射及手柄模拟

## 高级功能

### 变速齿轮（Windows）

通过 DLL 注入 Hook Windows 计时 API，改变游戏时间流速。

预设挡位：

| 挡位 | 用途 |
|------|------|
| 0.25x / 0.5x | 慢动作解析 |
| 1x | 正常速度 |
| 4x / 8x / 16x | 加速通关 |
| 32x / 64x / 128x | 快速跳过 |

- 支持自定义倍速输入（0.01 ~ 128x）
- 可视化速度条，实时显示当前状态
- **启动前请先加载 Flash 游戏页面**，否则无法注入
- 超过 16x 有崩溃风险——高倍速会冲击 Flash 自身计时逻辑，请按游戏承受能力选择，追求稳定建议不超过 8x
- 切换 / 重载游戏后变速会**自动重新注入并恢复当前倍速**，无需手动重启；插件崩溃会尝试自动恢复
- 快捷键：`F1` 启用变速，`F2` 切回原速

### 自动化（Windows）

- **操作录制 / 回放** — 在游戏画面上覆盖透明层捕获鼠标与键盘操作，精确到毫秒级时间戳；长按 / 拖拽在录制与回放时表现一致
- **后台播放** — 回放直接注入游戏画面的输入管线，**不占用物理鼠标键盘**，播放期间可正常使用电脑做别的事
- **断点续跑** — 录制时按 `F9` 打断点，回放至断点处结合 OCR 识别结果判断是否继续
- **热键槽位** — `F3` / `F4` / `F5` 各绑定一个脚本一键启动；播放中游戏区顶部显示「正在播放」悬浮徽标，随时按 `F10` 停止
- **OCR 图像识别** — 集成 Paddle OCR（首次使用自动下载模型），支持屏幕文字识别和条件判断
- **连点器** — 自定义按键序列与每步延时，可设循环次数（0 为无限）；鼠标按键步骤在游戏画面上取点

> 录制、回放、连点器均需**先打开游戏**——脚本坐标绑定到游戏画面。v0.0.7 及更早版本录制的脚本因回放管线重构已无法播放，请重新录制。

## 使用指南

### 变速齿轮

1. 先加载 Flash 游戏页面
2. 在顶栏选择预设挡位或输入自定义倍速
3. 按 `F1` 启用变速，`F2` 切回原速
4. 切换 / 重载游戏后变速自动恢复，无需手动重启

### 自动化脚本

1. 先打开要操作的游戏（脚本坐标绑定到游戏画面）
2. 在「操作自动化」标签页点击「新建录制」并填写脚本名称
3. 录制器缩为底部工具条，点击红点开始捕捉；录制中可按 `F9` 打断点，按 `F10` 停止并保存
4. 在自动化列表中点击播放回放，或把脚本绑定到 `F3` / `F4` / `F5` 热键槽一键启动
5. 回放为后台注入，不抢占鼠标键盘；播放中按 `F10` 或点击悬浮徽标上的停止按钮结束

### 连点器

1. 先打开游戏，在「设置 → 连点器」中添加按键序列
2. 每一步设置延时（按下该键前的等待时间），用于控制点击频率
3. 鼠标按键步骤需点击「未选择」按钮，在游戏画面上选取点击位置
4. 设置循环次数（0 为无限循环）后启动，运行中按 `F10` 停止

### OCR

- 首次使用自动下载 Paddle OCR 模型（下载包约 90 MB，解压约 250 MB），优先从 Cloudflare R2 拉取，失败时回落到 GitHub Releases
- 脚本断点处可手动框选识别区域
- 识别结果用于条件判断

### 环境要求

- Node.js 18+
- Windows / macOS

```bash
npm install
npm run dev
```

```bash
# Windows 安装程序
npm run dist:win

# Windows 便携版
npm run dist:win:portable

npm run dist:mac
```

## 常见问题

**找不到 Flash 插件？**
确保系统安装了 PPAPI（Pepper）版 Flash Player，不是 NPAPI 也不是 ActiveX。F-Box 自动寻找 `pepflashplayer*.dll`。

**变速齿轮无法启动？**
变速需要先加载 Flash 游戏页面再启用（注入到游戏进程）。若仍无反应，请将应用目录加入杀毒软件白名单，DLL 注入可能被拦截。

**OCR 功能异常？**
首次使用需下载 OCR 模型，确保网络连接正常（先试 Cloudflare R2，再试 GitHub）。模型下载完成后即为本地识别，不再联网。

**以前录的脚本点播放没反应？**
v0.0.7 及更早的脚本用的是屏幕绝对坐标 + 物理回放，已被后台注入方案取代，需重新录制。回放要求对应的游戏页面处于打开状态。

**游戏运行中频繁崩溃？**
Flash 对高倍速较敏感——先降低变速倍数（超过 16x 崩溃风险明显增大）。仍不稳定时，在「设置 → 显示」开启实验性「Flash 稳定性增强」（强制 CPU 合成，需重启生效）。崩溃后 F-Box 会自动尝试重新加载。

更多问题见[官网常见问题](https://fbox.dpdns.org/faq/)。
