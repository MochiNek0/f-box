# F-Box: 极简 Flash 游戏浏览器

F-Box 是一款基于 Electron 开发的轻量级浏览器，专为现代系统中的 Flash 游戏体验而设计。它解决了现代浏览器停止支持 Flash 的痛点，提供简洁、高效且功能丰富的 Flash 游戏运行环境。

---

## 核心功能

### 基础浏览

- **🚀 原生 Flash 支持** — 自动扫描系统中的 Pepper Flash 插件，无需繁琐配置
- **📑 多标签页浏览** — 现代标签页设计，支持同时运行多个游戏，快速切换
- **🪟 智能弹窗接管** — 自动接管弹窗游戏（如赛尔号、洛克王国）
- **📁 托盘后台** — 最小化至系统托盘，随时待命

### 个性化体验

- **🕵️ 隐私老板键** — 全局快捷键（默认 `Esc`）一键隐藏/呼出窗口
- **🌫️ 窗口透明度** — 全局窗口透明度调节，与桌面背景完美融合
- **🖥️ 画面分辨率** — 「设置 → 显示」可选「自动」（匹配屏幕，高清渲染）或「原始」（固定 1280）
- **⚙️ 可视化设置面板** — 轻松调节各项参数

### 游戏辅助（Windows）

- **🎮 游戏库管理** — 内置精选游戏入口，支持自定义添加游戏链接
- **🕹️ 键位映射** — 基于 AutoHotkey，支持键盘重映射及手柄模拟

## 高级功能

### ⚡ 变速齿轮（Windows）

通过 DLL 注入 Hook Windows 计时 API，改变游戏时间流速。

**支持的挡位：**

| 挡位 | 用途 |
|------|------|
| 0.25x / 0.5x | 慢动作解析 |
| 1x | 正常速度 |
| 4x / 8x / 16x | 加速通关 |
| 32x / 64x / 128x | 快速跳过 |

- 支持自定义倍速输入（0.01 ~ 128），上限为 128x
- 可视化速度条，实时显示当前状态
- **提示**：启动前请先加载 Flash 游戏
- **稳定性**：超过 16x 会提示崩溃风险——高倍速会冲击 Flash 计时逻辑，容易导致插件崩溃，请按游戏承受能力选择
- 切换 / 重载游戏后变速会**自动重新注入并恢复当前倍速**，无需手动重启；若插件崩溃会尝试自动恢复

### 🤖 自动化工具（Windows）

- **📹 操作录制/回放** — 在游戏画面上覆盖透明层捕获鼠标与键盘操作，精确到毫秒级时间戳；长按 / 拖拽在录制与回放时表现一致
- **🎯 后台播放** — 回放直接注入游戏画面的输入管线，**不占用物理鼠标键盘**，播放期间可以正常使用电脑做别的事
- **⏸️ 断点续跑** — 录制时按 `F9` 打断点，回放至断点处结合 OCR 识别结果判断是否继续
- **⌨️ 热键槽位** — `F3` / `F4` / `F5` 各可绑定一个脚本一键启动；播放中游戏区顶部显示「正在播放」悬浮徽标，随时可按 `F10` 停止
- **👁️ OCR 图像识别** — 集成 Paddle OCR 引擎（首次使用自动下载），支持屏幕文字识别和条件判断
- **🖱️ 连点器** — 自定义按键序列与每步延时，可设循环次数（0 为无限）；鼠标按键步骤支持在游戏画面上取点

> **注意**：录制、回放、连点器均需**先打开游戏**——脚本坐标绑定到游戏画面。v0.0.7 及更早版本录制的脚本因回放管线重构已无法播放，请重新录制。

## 技术栈

| 分类 | 技术 |
|------|------|
| 框架 | React 19 + TypeScript |
| 构建 | Vite 5 |
| 桌面 | Electron 11 |
| 样式 | Tailwind CSS |
| 状态 | Zustand |

- OCR: Paddle OCR（本地部署）

## 快速开始

### 环境要求

- Node.js 18+
- Windows/macOS
- Flash 插件（自动检测）

### 安装运行

```bash
npm install
npm run dev
```

### 打包构建

```bash
# Windows 安装程序
npm run dist:win

# Windows 便携版
npm run dist:win:portable

# macOS
npm run dist:mac
```

## 使用指南

### 变速齿轮

1. 先加载 Flash 游戏页面
2. 在顶栏选择预设挡位（4x ~ 128x）或输入自定义倍速
3. 点击启用按钮（或按 `F1` 变速 / `F2` 切回原速）
4. 切换 / 重载游戏后变速会自动恢复，无需手动重启

### 自动化脚本

1. 先打开要操作的游戏（脚本坐标绑定到游戏画面）
2. 在「操作自动化」标签页点击「新建录制」并填写脚本名称
3. 录制器缩为底部工具条，点击红点开始捕捉；录制中可按 `F9` 打断点，按 `F10` 停止并保存
4. 在自动化列表中点击播放回放，或把脚本绑定到 `F3` / `F4` / `F5` 热键槽一键启动
5. 回放为后台注入，不抢占鼠标键盘；播放中按 `F10` 或点击悬浮徽标上的停止按钮结束

### 连点器

1. 先打开游戏，在「设置 → 连点器」中添加按键序列
2. 每一步可设置延时（按下该键前的等待时间），用于控制点击频率
3. 鼠标按键步骤需点击「未选择」按钮，在游戏画面上选取点击位置
4. 设置循环次数（0 为无限循环）后启动，运行中按 `F10` 停止

### OCR 功能

- 首次使用自动下载 Paddle OCR 模型（约 200MB），优先从 Cloudflare R2 拉取，失败时回落到 GitHub Releases
- 脚本断点处可手动框选识别区域
- 识别结果用于条件判断

## 常见问题

**Q: 找不到 Flash 插件？**
A: 确保系统安装了 PPAPI 版 Flash Player。F-Box 自动寻找 `pepflashplayer*.dll`。

**Q: 变速齿轮无法启动？**
A: 请将应用目录加入杀毒软件白名单，DLL 注入可能被拦截。

**Q: OCR 功能异常？**
A: 首次使用需下载 OCR 模型，确保网络连接正常（先试 Cloudflare R2，再试 GitHub）。

**Q: 以前录的脚本点播放没反应/报错？**
A: v0.0.7 及更早的脚本用的是屏幕绝对坐标 + 物理回放，已被后台注入方案取代，需重新录制。另外回放要求对应的游戏页面处于打开状态。

**Q: 游戏运行中频繁崩溃？**
A: Flash 插件对高倍速较敏感——请先降低变速倍数（超过 16x 时崩溃风险明显增大）。仍不稳定时，可在「设置 → 显示」中开启实验性「Flash 稳定性增强」开关（强制 CPU 合成，需重启生效）。崩溃后 F-Box 会自动尝试重新加载恢复。
